# 智安工坊

**人工智能实验安全风险识别与应急处置虚拟仿真实验**

申报方向：2026 年度“人工智能+”虚拟仿真实验教学项目 · 实验室安全（人工智能实验安全）

学生在一个贯穿全程的实验情景中，完成从实验室准入、数据处理、模型与智能体配置、设施运维到事故处置与复盘的 24 步交互操作。每一步的结果由仿真模型按学生的操作实时计算，系统自动赋分并生成五维能力画像与实验报告。

> 实验情景：课题组用一份含个人信息的校园问卷数据（2000 条）微调开源 7B 大模型，并部署一个可调用“文件读取、邮件发送”等工具的智能体，训练与推理运行在实验室 GPU 服务器上。

## 快速开始

环境：Node.js ≥ 22、pnpm ≥ 9。

```bash
pnpm install
pnpm dev
```

- 前端：http://localhost:5174
- 后端：http://localhost:8788/api/health

首次启动会随机生成 admin / teacher / student 三个初始账号，密码写入 `apps/server/data/initial-accounts.txt`（仅本机保存，已被 `.gitignore` 排除）。**系统不内置任何默认口令。**

接入大模型（可选）：复制 `.env.example` 为 `apps/server/.env`，填写 OpenAI 兼容接口。不配置时由规则引擎兜底，实验流程不受影响。

| 命令 | 作用 |
|---|---|
| `pnpm dev` | 同时启动前后端 |
| `pnpm -r test` | 运行全部测试（164 个：评分 60、仿真 19、前端世界与步态 18、后端 67） |
| `pnpm -r typecheck` | 全仓库类型检查 |

## 三维科研基地（前端）

登录后进入同一个持续存在的程序化三维基地（约 36m × 24m，五个功能区经走廊与门洞相连），以研究员身份走到设备旁完成 24 步任务：

| 区域 | 设备与步骤 |
|---|---|
| 准入与简报区 | 身份核验终端 S01 · 任务简报台 S02–S03 |
| GPU 机房 | 机房巡检台 S04 · 配电与上电控制台 S18/S20 · 散热监控台 S19 |
| 数据实验室 | 数据处理终端 S05–S09 · 泄露应急终端 S10 |
| 模型与智能体区 | 模型合规终端 S11–S13/S17 · 提示注入隔离沙箱 S14–S15 · 智能体权限控制台 S16 |
| 审计与复盘室 | 日志审计终端 S21 · 复盘与报告终端 S22–S24 |

操作：WASD/方向键移动，鼠标拖动转视角，E 交互，H 三层提示（目标→位置→控件说明，不给答案），Esc 返回；也可点“自动前往当前任务”。

- 场景、人物、设备、标牌全部由代码程序化生成，不使用外部模型、贴图或 HDRI
- 设备表现只来自真实接口：S16 攻击路径按服务端 trace 分支绘制，S19 告警依据后端温度曲线，提交前一律显示“待验证”
- 已提交的历史步骤只读回看；修改已提交的输入后旧结果标为“上次提交结果”
- 画质高/中/低与“减少动态”可在设置中切换；设置面板显示本机实测帧率与 p95 帧时间
- 浏览器不支持 WebGL 或渲染上下文丢失时，自动切换为 HTML 实验模式（同样的字段、提交与评分）

## 仿真模型（`packages/sim-core`）

全部为纯函数，结果由学生操作决定，可单元测试。

| 模型 | 用于 | 说明 |
|---|---|---|
| 风险分级 | S02 | 数据敏感度 + 模型规模 + 工具外发能力综合判定 |
| 个人信息识别与脱敏 | S06 | 正则识别手机号与身份证号；隐私风险指数与数据可用性双目标 |
| 提示注入检测 | S14 | 覆盖指令、角色越狱、间接注入、数据外发、索取机密五类特征 |
| 数据投毒检测 | S08 | 确定性随机数据集（200 条含 12 条投毒），按阈值计算精确率、召回率、F1 |
| 密钥泄露检测 | S13 | 24 小时调用量序列，按告警阈值计算检测效果 |
| 公平性评估 | S17 | 人口统计均等差、机会均等差 |
| GPU 热路模型 | S19 | 一阶热路：C·dT/dt = P − (T − T_in)/R，功耗随负载、热阻随风扇转速变化 |
| 审计追溯 | S21 | 审计事件按时段与账号检索 |
| 智能体越权攻击 | S16 | 模拟间接注入诱导“读取问卷并外发”，按工具权限判定每一跳是否执行 |

GPU 热路等为教学降阶模型，用于快速反馈，不替代厂商热设计数据。

## 赋分（`packages/scoring`）

- 勾选题：选对加分、选错扣分、不选不得分
- 排序题：按 Kendall 一致对比例计分
- 检测题：按 F1 计分，并以该数据集可达到的最优 F1 归一化
- 脱敏题：隐私 70% + 可用性 30%，以全部策略组合中的最优解归一化
- 每一步都有测试保证：标准答案得满分、不动默认值得不到满分

能力画像五个维度：安全意识与规范 18、数据安全 28、模型与智能体安全 31、设施与运维安全 17、复盘与改进 6。

## AI 应用

- **安全助手评审**（S10、S23）：大模型评审学生方案，输出结构化风险清单；超时或不可用时由规则引擎兜底
- **实时仿真反馈**（S06、S08、S13、S17、S19、S21）：参数变化后即时返回仿真曲线或脱敏结果
- **实验报告生成**（S24）：汇总全过程记录、五维能力画像与改进建议
- 所有模型调用写入 `ai_logs`；提示词中不包含学生个人信息
