每个知识点在系统中关联到具体步骤（`packages/shared/src/curriculum.ts`），学生在操作面板中可展开查看。

### 3-4（2）核心要素仿真设计

11 个确定性仿真模型，结果由学生操作计算：风险分级、文本个人信息识别与脱敏、**人脸图像去标识化**（高斯低通/马赛克，拉普拉斯高频能量衡量身份细节残留，护目镜亮度对比衡量任务信息保留）、训练数据投毒检测（200 条样本，阈值—F1）、密钥泄露检测（24 小时调用量）、提示注入特征识别、智能体越权外发（读取后分邮件/检索/命令三条分支）、公平性指标、GPU 一阶热路模型（C·dT/dt = P − (T − T_in)/R，83 °C 上限）、审计日志检索、排序一致性。三维场景为程序化建模的五区科研基地。

### 3-4 人工智能应用设计（系统现状）

- **AI 实验导师（智能体）**：实验前给出方案设计思路与知识点推荐；实验中分析学生当前的仿真数据（如图像细节残留比例、温度曲线越线情况）；实验后结合成绩、阶梯能力与尝试记录给出反思改进与创新探索路径。
- **安全助手评审**：对 S10、S23 的处置方案给出风险清单。
- **课程知识库**：29 个知识点，只写原理不写答案（有自动化测试保证不含所属步骤的选项原文）。
- **可信可控**：发给模型的内容不含个人信息与评分规则；输出过滤手机号、身份证号；模型不可用时知识库规则兜底并如实标注来源；每次调用写入审计表，2026 `ai_data` 由审计自动汇总。
- **现状说明**：目前未配置真实大模型，所有指导由知识库规则生成，`ai_call_count` 为 0。申报前需接入真实模型（名称、版本、部署方式），否则“人工智能应用”一栏缺少实际支撑。

### 3-4 真实产业场景融入（需补充）

系统情景来自高校 AI 实验室的典型工作流程（问卷数据微调大模型、部署可调用工具的智能体、GPU 机房运维）。征集说明要求“以产业真实数据为牵引”，目前数据为程序合成；建议补充：合作企业或学校网信部门提供的脱敏案例、真实机房巡检规程，以及可选的“产业对接证明材料”。

### 3-6 步骤要求

学生交互性操作 **23 步**（S01–S23，均为选择、配置、排序或参数研判），S24 为自动报告，不计入。系统按服务器记录的“打开设备—改动输入—提交”判定每一步是否有真实交互证据，并在回传前检查 ≥20 步。

### 3-7 不同操作下的结果（举例）

- S06：保留原图 → 身份细节 100% 残留；人脸区域涂黑 → 隐私受保护但护目镜信息丢失；高斯模糊半径 2–4 → 细节残留低于 20% 且护目镜对比保留 70% 以上。
- S16：文件读取被禁止 → 攻击链只有一个“被拦截”节点；读取执行而外发工具自动允许 → 邮件、检索、命令三条分支全部执行，数据外发。
- S19：风扇 30% / 负载 90% → 峰值约 92 °C 超过 83 °C；提高风扇转速 → 峰值降至限值以下。

## 4. 评价与能力画像（建设标准 2、4）

- 结果评价：24 步原评分规则，满分 100（确定性，不使用模型打分）。
- 阶梯式能力标准：L1 安全认知与规范操作（8 步）→ L2 综合设计与安全配置（7 步）→ L3 复杂问题研判与应急处置（8 步），层级得分率 ≥60% 为达成、≥85% 为优秀。
- 过程评价（不计入成绩）：真实交互步数、提交与重复尝试、有效操作时长、提示/导师/评审使用次数。
- 五维能力画像 + 成长档案（本人历次实验的得分与层级达成）。

## 7. 技术架构

- 开发技术：3D 仿真、HTML5；工具：其他（TypeScript、React、Three.js / React Three Fiber、Node.js、Vite）；未使用 Unity / Blender 等商业或外部 3D 资产。
